# AI-beszélgetések exportja

A fejlesztés Claude Code-dal (VS Code-bővítmény) készült. A beszélgetés exportja ebbe a mappába kerül.

**Export előtt:** a beszélgetésben a feladatleírás teljes szövege, benne az OpenRouter-kulcs is szerepel.
Ezt az exportból ki kell venni (`sk-or-v1-...` keresése), mielőtt a fájl a repóba kerül.

A meghatározó promptok, döntések és az AI tévedései időrendben: [../AI_NAPLO.md](../AI_NAPLO.md).
